更新日志

1.0.0 Beta 3 RE

  1. 现在模组可以通过Mod Menu模组自动检查更新了。
  2. SST（Show Spawn Time）功能测试Ver1：
    信息显示功能 （感觉没用 需自行输入/fzh beta ShowSpawnTime true开启）
  1. 新增 扩展了帮助列表，新增配置项的帮助。
  2. 新增 /lang 指令，可快速切换语言并立即重载资源。（虽然不知道有没有用）
  3. 修改 当玩家延迟显示为0ms将变为灰色。
  4. 修改 部分英文翻译。
  5. 修改 配置项“displayMode”：
    “HEALTH”简化为“HP”，
    “DISTANCE”简化为“DIST”。
  6. 修复 /fzh set position命令直接执行不会显示当前HPDP显示位置，反而/fzh set会触发，并且还无法正常显示数值。
